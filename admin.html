1. 概述

本指南帮助非技术人员维护和更新上海子爱实业海外独立站。网站采用静态HTML技术，无需数据库，简单易维护。

提示： 网站文件位于服务器目录 /root/.openclaw/agents/protoss0928/website/ziai-site/
需要的技术技能：
  • 基本的电脑操作能力
  • 简单的文字编辑（使用文本编辑器如 VS Code、Notepad++）
  • 复制粘贴能力
维护内容：
  • 更新产品价格和信息
  • 修改公司介绍内容
  • 添加新产品或分类
  • 更新联系方式
  • 更换图片素材

2. 文件结构

网站文件结构清晰，每个页面都是独立的HTML文件：

website/ziai-site/ ├── index.html ← 首页 ├── about.html ← 关于我们 ├── products.html ← 产品中心 ├── contact.html ← 联系我们 ├── admin.html ← 本维护指南（勿删除） ├── versions.html ← 版本历史页面 ├── en/ ← 英文版页面 │ ├── index.html │ ├── about.html │ ├── products.html │ └── contact.html └── images/ ← 图片资源 ├── logo.png ├── products/ └── ...
重要： 修改前请务必备份原文件。每次修改会自动生成版本快照，可随时回滚。

3. 编辑页面

3.1 使用文本编辑器

推荐使用以下编辑器之一：

  • VS Code（推荐）- 免费，功能强大
  • Notepad++ - 轻量级，适合初学者
  • Sublime Text - 速度快
3.2 编辑步骤
1
打开文件

用文本编辑器打开要修改的HTML文件

2
找到要修改的内容

使用 Ctrl+F 搜索关键词定位

3
修改内容

直接编辑文字，不要修改HTML标签（如 <h1>, <p>, <div> 等）

4
保存文件

按 Ctrl+S 保存修改

中英文同步： 网站有中文版和英文版两个版本。修改中文内容后，请同步修改 en/ 文件夹下对应的英文版本。

4. 更新内容

4.1 更新产品信息

打开 products.html，找到对应的产品分类，使用 Ctrl+F 搜索产品名称。

产品卡片结构示例：
<div class="col-md-4 mb-4"> <div class="card product-card"> <img src="images/products/your-product.jpg" alt="产品名称"> <div class="card-body"> <h5 class="card-title">产品名称</h5> <p class="card-text">产品描述内容...</p> <a href="contact.html" class="btn btn-sm btn-primary">询价</a> </div> </div> </div>
4.2 更换图片
  1. 将新图片放入 images/ 或 images/products/ 目录
  2. 图片格式支持：JPG、PNG、GIF
  3. 推荐尺寸：产品图 400x300 像素，banner图 1920x600 像素
  4. 修改HTML中对应的 src="images/..." 路径
4.3 更新联系方式

打开 contact.html，修改以下内容：

  • 电话号码：搜索 021-
  • 邮箱：搜索 @
  • 地址：搜索 地址 或 Address
4.4 更新公司介绍

打开 about.html，修改关于我们的内容。

5. 发布网站

自动化发布： 网站已配置自动部署。每次修改完成后，运行发布脚本即可自动：
  • 创建版本快照
  • 自动更新版本号和日期
  • 发布到 GitHub Pages
  • 保留最近3个历史版本
发布步骤：
# 1. 进入网站目录 cd /root/.openclaw/agents/protoss0928/website/ziai-site # 2. 提交修改（替换 YOUR_MESSAGE 为本次修改说明） git add . git commit -m "YOUR_MESSAGE" git push # 3. 运行部署脚本（自动发布+版本管理） cd /root/.openclaw/agents/protoss0928/website ./deploy.sh
发布后验证：
  1. 等待约1-2分钟让GitHub Pages更新
  2. 访问 https://protoss0928.github.io/ziai-site/ 查看
  3. 检查修改是否生效

6. 版本回滚

网站自动保留最近3个版本。如需回滚到之前的版本：

方法一：使用版本历史页面
  1. 访问 versions.html 查看版本历史
  2. 找到要回滚的版本
  3. 点击"回滚到此版本"按钮
方法二：使用命令行回滚
# 1. 查看所有版本 cd /root/.openclaw/agents/protoss0928/website/ziai-site git log --oneline # 2. 查看可用备份 ls -la /root/.openclaw/agents/protoss0928/website/ # 3. 恢复到指定版本（替换 VERSION_ID 为git log中的版本号） git checkout VERSION_ID # 4. 重新发布 cd /root/.openclaw/agents/protoss0928/website ./deploy.sh
方法三：从备份目录恢复
# 查看备份目录 ls -la /root/.openclaw/agents/protoss0928/website/ # 如果有 ziai-site-v2 或 ziai-site-v3 备份 # 可以复制备份内容覆盖当前版本，然后重新发布 cp -r /root/.openclaw/agents/protoss0928/website/ziai-site-v2/* /root/.openclaw/agents/protoss0928/website/ziai-site/
注意： 回滚会覆盖当前修改。回滚前请确保已保存重要更改。

7. 常见问题

可能是浏览器缓存问题。尝试按 Ctrl+Shift+R 强制刷新页面，或清除浏览器缓存。

检查：1) 图片文件是否存在；2) 路径是否正确；3) 图片格式是否为 JPG/PNG/GIF。

GitHub Pages 需要1-2分钟更新。等待后刷新页面。如仍不显示，尝试清除浏览器缓存。

使用版本回滚功能恢复。参见第6节"版本回滚"。
