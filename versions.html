# 查看所有Git版本 cd /root/.openclaw/agents/protoss0928/website/ziai-site git log --oneline # 查看可用备份目录 ls -la /root/.openclaw/agents/protoss0928/website/ # 恢复到指定版本 git checkout [VERSION_ID] # 或从备份目录恢复 cp -r /root/.openclaw/agents/protoss0928/website/ziai-site-v2/* /root/.openclaw/agents/protoss0928/website/ziai-site/
版本管理说明
自动版本控制

每次发布网站时，系统会自动：

  • 更新内部版本号和日期
  • 创建Git提交记录
  • 保留备份副本
版本保留策略
  • Git历史：完整保留所有版本
  • 备份目录：保留最近3个版本
  • 版本标签：格式 vYYYYMMDD
回滚前提条件
  • 确认要回滚的版本日期
  • 保存当前版本的修改（如果有）
  • 了解回滚会影响的内容
注意： 回滚会覆盖当前网站内容。请谨慎操作！
